Occipital lobe

lobus occipitalis

Location. Back of the brain.

Anatomy. Contains the primary visual cortex receiving the crossed optic signals.

Function. Visual processing: edges, motion, colour and form, then object recognition.

Works with. Parietal lobe; Temporal lobe; Thalamus

Processes. Feature detection, Colour processing, Image assembly

When it goes wrong. Cortical blindness after damage; Visual processing deficits
